# 時光地圖：世界歷史疆域

互動式世界歷史地圖：拖動時間軸，看看西元前500年到今天共18個時代的世界版圖。

**網站：** https://a20051024941024-ctrl.github.io/Time-map/

## 功能
- 18個年代的國家疆域、君主、首都與介紹
- 字幕＋語音導覽（可調速度）
- 城市、戰役與大事、貿易路線圖層
- 搜尋、版圖排行、歷史測驗

## 說明
- 歷史疆域是依史料以現代國界切塊近似繪製，邊界與面積僅供學習參考。
- 世界輪廓：Apache ECharts 內建世界地圖（Apache License 2.0，源自 Natural Earth），於網頁開啟時從 jsDelivr 載入。
- 繪圖函式庫：D3.js（ISC License）。
- 君主頭像為依文化與時代設計的插畫造型，並非本人肖像。
